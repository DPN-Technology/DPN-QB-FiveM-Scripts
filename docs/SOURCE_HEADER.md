# DPN Technology Source Header Standard

For new source files created as part of DPN QB FiveM Scripts, use a concise ownership header where appropriate.

## Lua

\`\`\`lua
--[[
    DPN Technology — DPN QB FiveM Scripts
    Created by Diesel, CEO of DPN Technology

    Licensed under the DPN Technology Community Source License (DPN-CSL).
    Use and modification are permitted under the license.
    Commercial resale requires explicit DPN Technology authorization.

    Official repository:
    https://github.com/directordiesel/DPN-QB-FiveM-Scripts
]]
\`\`\`

## Guidance

Do not add a DPN ownership header to third-party code that DPN Technology does not own.

Preserve third-party copyright and license notices.
