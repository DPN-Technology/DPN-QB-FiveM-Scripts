# DPN Standalone FiveM Resources

Official framework-independent or standalone resources published by **DPN Technology**.

**Created under the direction of Diesel, CEO of DPN Technology.**

Standalone means a resource does not require QBCore as its core framework dependency. Individual resources may still depend on common FiveM libraries such as ox_lib, oxmysql, target systems, or other documented dependencies.

Every resource should clearly document:

- Dependencies
- ACE permissions
- Installation
- Configuration
- Public APIs
- Security considerations
- Upgrade requirements
- License
