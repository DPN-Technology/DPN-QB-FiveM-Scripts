# DPN Technology Project Governance

## Project Identity

**Project:** DPN QB FiveM Scripts  
**Organization:** DPN Technology  
**Founder / Original Creator:** Diesel  
**Role:** CEO of DPN Technology

This repository is an official DPN Technology FiveM development project.

## Mission

Provide high-quality free FiveM scripts that server owners can inspect, modify, learn from, and deploy while preserving creator attribution and preventing unauthorized commercial resale.

## Project Authority

The official repository is maintained under DPN Technology's direction.

Final authority over:

- Official releases
- Roadmap
- Repository structure
- Branding
- Licensing
- Commercial permissions
- Maintainer appointments
- Security response
- Deprecation decisions
- Release acceptance

rests with DPN Technology, led for this project by **Diesel, CEO of DPN Technology**, unless DPN Technology formally delegates authority.

## Community Role

Community members may:

- Report issues
- Suggest features
- Submit pull requests
- Maintain forks
- Improve documentation
- Propose framework support
- Share non-commercial modifications under the license

Community contribution does not convert the official repository into an unmanaged project or transfer DPN Technology ownership.

## Maintainers

Authorized maintainers may review issues, review code, merge approved changes, manage labels, and help maintain releases according to permissions granted by DPN Technology.

## Release Levels

DPN resources may be marked:

- Experimental
- Alpha
- Beta
- Release Candidate
- Stable
- Legacy
- Archived

## Decision Priorities

When evaluating changes, maintainers should prioritize:

1. Security
2. Data integrity
3. Stability
4. Compatibility
5. Performance
6. Maintainability
7. Configurability
8. User experience
9. Documentation
10. New features

**We Develop what doesn't exist. We Pioneer what comes next. We Navigate the future.**
