# DPN QB FiveM Scripts Support

This repository contains public FiveM resources maintained by DPN Technology.

## Before requesting support

- Read the resource-specific `README.md` and the main repository `README.md`.
- Confirm the resource is installed in the correct catalog/context and that all documented dependencies are present.
- Review your FiveM server console for the first relevant error, not only downstream failures.
- Run the repository validation tools when developing or modifying a resource.
- Verify that local modifications have not changed required event names, exports, dependencies, file paths, or manifest entries.

## Bug reports

Use the repository issue templates and include:

- Resource name and version
- QBCore/standalone/hybrid context
- FiveM artifact/server version where relevant
- Reproduction steps
- Expected behavior
- Actual behavior
- Relevant sanitized logs or console output
- Whether the issue occurs on an unmodified copy of the resource

Never include passwords, tokens, API keys, webhooks, private keys, connection strings, private server configuration, or other credentials in an issue.

## Security issues

Potential security vulnerabilities should be reported according to `SECURITY.md`, not posted publicly when disclosure could put users or servers at risk.

## Commercial-use questions

See `LICENSE` and `COMMERCIAL_PERMISSION.md`. Commercial redistribution or sale of DPN Technology scripts may require explicit permission from DPN Technology.

## Scope

Support is best-effort for public releases. DPN Technology cannot guarantee compatibility with every third-party framework modification, fork, dependency version, or custom server configuration.
