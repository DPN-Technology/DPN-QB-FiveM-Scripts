# DPN Technology FiveM Support Policy

This repository contains free community resources created by **Diesel, CEO of DPN Technology**.

DPN Technology wants issues to be reproducible, actionable, and useful to everyone using the resource.

## Before Requesting Support

Confirm:

- The resource is the latest version you intended to install.
- Required dependencies are installed.
- Dependencies start before the DPN resource.
- Required SQL has been imported.
- The configuration has been reviewed.
- You tested an unmodified copy when possible.
- You checked both the server console and F8 console.
- You are not exposing credentials in your report.

## Include

- DPN resource name
- Commit/version
- FiveM artifact version
- Framework and version
- Relevant dependencies
- Reproduction steps
- Expected behavior
- Actual behavior
- Console errors
- Whether you modified the script

## Scope

Free support may include reasonable help with:

- Reproducible bugs
- Installation documentation
- Compatibility issues
- Security reports
- Clarifying configuration
- Confirmed regressions

Free release does not create an obligation for custom server development, private integrations, framework conversions, or support for heavily modified forks.

## Commercial Questions

Questions about permission to commercially distribute DPN scripts must be directed to **Diesel, CEO of DPN Technology**, through an official DPN Technology channel.

Do not assume permission because a request has not yet received a response.
