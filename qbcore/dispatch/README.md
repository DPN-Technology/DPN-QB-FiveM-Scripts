## Scope

## Framework

**QBCore**

## How Scripts Are Stored

Each actual script gets its own folder inside this category:

```text
category/
└── dpn-resource-name/
    ├── fxmanifest.lua
    ├── resource.json
    ├── README.md
    ├── config.lua
    ├── client/
    └── server/
```

Every DPN resource should follow the repository development, security, testing, documentation, and licensing standards.
