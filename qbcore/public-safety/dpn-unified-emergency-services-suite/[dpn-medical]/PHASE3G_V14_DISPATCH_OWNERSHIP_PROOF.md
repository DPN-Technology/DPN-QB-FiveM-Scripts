# Phase 3G — v14 Medical Dispatch Ownership Proof

Baseline: `main` at `71c3f27dab3a9311d7482654f801277ea7735ae3`.

## Purpose

This proof records a current-main Phase 3G audit of `dpn-medical-dispatch/server/v14.lua` after the v9-v12 compatibility-routing integration.

The result remains conservative: **v14 does not require the compatibility-router rewrite used by v9-v13.** The v14 layer emits local medical events and does not directly select or broadcast into an external dispatch namespace.

## Audited v14 surfaces

`server/v14.lua` exposes:

- `CreateTraumaCodeV14`
- `RecommendTraumaAssetsV14`
- `EscalateTraumaIncidentV14`
- `GetV14DispatchBoard`
- `GetV14Cases`

The event-emitting workflows are:

- `CreateTraumaCodeV14` → `TriggerEvent('dpn-medical:v14:trauma_code', item)`
- `EscalateTraumaIncidentV14` → `TriggerEvent('dpn-medical:v14:incident_escalation', item)`

Current-main source contains no direct `dpn-dispatch-system` or `dpn-dispatch` publication in `server/v14.lua`.

## Ownership conclusion

1. v14 owns trauma-command case construction, persistence, board state, risk/tier/destination/resource-demand data, and local medical event publication.
2. v14 does not currently own external dispatch-resource selection.
3. `DPNMedicalDispatchCompatBridge` should not be inserted into v14 merely for symmetry when no external compatibility fan-out exists.
4. Any consumer that turns a v14 local event into an external dispatch call is the correct place to evaluate external dispatch ownership.
5. A future runtime change is warranted only if fresh evidence shows v14 directly selecting multiple external dispatch targets or duplicate external calls being generated by its consumers.

## Safety / no-change decision

No v14 runtime code is changed by this proof. Existing exports, events, persistence, case state, scoring, recommendations, payloads, permissions, compatibility behavior, and CI remain unchanged.

Before any later v14 runtime patch, re-run the audit from then-current `main` and require concrete evidence of an external ownership collision.
