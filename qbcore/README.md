# DPN QBCore Resources

Official QBCore-compatible FiveM resources published by **DPN Technology**.

**Created under the direction of Diesel, CEO of DPN Technology.**

Each resource in this directory should include its own README describing:

- QBCore version expectations
- Dependencies
- Installation
- Shared items/jobs
- SQL
- Configuration
- Permissions
- Events/exports
- Security considerations
- Upgrade notes
- License

Do not assume every resource uses the same inventory, target, menu, or notification system.

All DPN-owned resources are subject to the repository license unless a resource explicitly states otherwise.
