# DPN QBCore Jobs

Official **DPN Technology** FiveM script category.

**Created under the direction of Diesel, CEO of DPN Technology**

## Scope

Whitelisted and public jobs, business systems, job utilities, duty systems, payroll integrations, and job-specific mechanics.

## Framework

**QBCore**

## Resource Requirements

Every script added to this category should include:

- `fxmanifest.lua`
- Script-specific `README.md`
- DPN Technology attribution
- Version information
- Framework/support status
- Dependency list
- Installation instructions
- Configuration documentation
- Permission documentation where relevant
- SQL/migration documentation where relevant
- Security considerations
- Upgrade notes for breaking changes
- Repository license reference

## Naming

Preferred DPN resource naming:

```text
dpn-resource-name
```
