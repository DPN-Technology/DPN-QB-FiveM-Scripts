# Third-Party Components and Licenses

This repository contains DPN Technology-owned source code and may also depend on third-party software.

## Ownership boundary

DPN Technology claims ownership only over original DPN-authored code and assets. Third-party packages, frameworks, libraries, tools, actions, fonts, media, and other external components remain subject to their respective upstream licenses and copyright notices.

## Source of truth

Dependency manifests, lockfiles, build definitions, workflow files, and generated SBOM/license reports are the source of truth for the exact versions used by a build.

Before a release:
1. Review new and updated dependencies.
2. Confirm each dependency is permitted for the intended commercial/internal use.
3. Preserve required notices and attribution.
4. Reject dependencies with incompatible or unknown licensing until reviewed.
5. Regenerate any SBOM or license inventory used by the project.

This file records the DPN ownership boundary and release policy; it does not replace upstream license text.
