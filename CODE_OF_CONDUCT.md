# DPN Technology Community Code of Conduct

DPN QB FiveM Scripts is an official DPN Technology community software project created by **Diesel, CEO of DPN Technology**.

We want technical discussion to stay productive and respectful.

## Expected Conduct

Participants should:

- Discuss code, behavior, bugs, and design decisions constructively.
- Provide useful reproduction steps when reporting problems.
- Respect contributors and maintainers.
- Keep disagreements focused on the work.
- Avoid harassment, threats, discriminatory abuse, or targeted personal attacks.
- Avoid spam and marketplace advertising in project issues.
- Avoid posting private credentials or personal information.
- Respect the repository license and third-party licenses.

## Unacceptable Conduct

The following may result in moderation:

- Harassment
- Threats
- Hate speech
- Doxxing
- Malicious spam
- Knowingly submitting malware
- Posting stolen or leaked paid scripts
- Repeatedly attempting to use project channels for unauthorized resale
- Intentionally misleading users about official DPN Technology releases
- Publishing sensitive exploit details irresponsibly when they could endanger active servers

## Technical Disagreement

Strong technical disagreement is allowed.

Critique the implementation, not the person.

Examples of useful disagreement:

- "This client event needs server-side validation because the reward amount is user-controlled."
- "This loop appears to run every frame even when the player is far away."
- "This database migration needs a rollback path."

## Enforcement

DPN Technology maintains moderation authority over official project spaces.

Project direction and final repository decisions remain under DPN Technology governance.
