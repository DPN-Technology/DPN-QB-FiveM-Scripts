# DPN Technology Commercial Permission Policy

DPN Technology releases the scripts in this repository for free community use under the repository license.

**Default rule: commercial resale is not authorized.**

## Who Can Authorize Commercial Distribution?

Commercial permission must come from:

**Diesel — CEO of DPN Technology**

or another DPN Technology representative who has been explicitly authorized to grant that permission.

## Permission Is Required For

Examples include:

- Selling an original DPN script
- Selling a modified DPN script
- Selling a QBCore-to-other-framework conversion containing DPN-derived code
- Putting DPN scripts into paid bundles
- Charging users to download DPN source
- Paid subscriptions that gate access to DPN scripts
- Rebranding DPN code as a paid product
- Sublicensing DPN code for resale
- Marketplace listings offering DPN-derived code for a fee

## Permission Is Normally Not Required For

Subject to the full LICENSE:

- Running the script on your FiveM server
- Editing it for your server
- Using it on a monetized server when the script itself is not being sold
- Learning from it
- Maintaining a free fork
- Sharing a free modification with required attribution
- Charging for genuine installation/configuration labor where the DPN code itself remains free and is not being sold as a licensed product

## Request Information

A commercial request should include:

1. Your name or business/project identity
2. DPN resource name
3. Description of your modification
4. Proposed product
5. Marketplace/distribution location
6. Intended selling price
7. Whether source is included
8. Whether buyers can redistribute
9. Attribution plan
10. Whether DPN branding remains
11. Whether the script is bundled with other products

## Authorization Record

Commercial permission should be retained in writing.

A valid authorization may define:

- Approved product
- Approved seller
- Approved marketplace
- Price restrictions
- Attribution requirements
- Duration
- Redistribution rights
- Revenue share, if any
- Revocation/termination conditions

## No Implied Permission

The following do not grant commercial rights:

- Public GitHub access
- A fork
- Stars
- Contributions
- Pull requests
- Modifications
- Prior free use
- A message that received no reply
- Someone other than an authorized DPN Technology representative saying resale is allowed
